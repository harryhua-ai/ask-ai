## Behavior/config changes

- 生产部署/回滚自 v1.0.0 起**必须显式不可变版本 tag**;`latest` 被拒绝;
  prod compose 未设 ASKAI_IMAGE_TAG 直接报错。
- /health 新增 version/git_sha/app_mode 字段(status 语义不变)。
- 数据源编辑:代码仓库/网站源默认 Simple Mode(自动发现 + 推荐策略),
  clone_path 等下沉高级选项;「拉取分支全量后缀预填」废除。
- 删除数据源为非阻塞生命周期操作;删除中/已删源不可被同步复活。
- GITHUB_TOKEN 只读最小权限校验(既有);发现类端点需 editor+。

## Known limitations

- 合法 unknown/shared 人群 1,252 chunks 按契约不参与产品定向证据;
- website-camthink 抓取存在持续 partial 的页面集合(既有观察);
- GPU 共享租户下大 batch embed 可能 OOM(#14 有界回退缓解,非消除);
- CI 构建镜像 ~9.6GB,镜像内清单断言步骤增加 runner 拉取开销。

## Rollback compatibility

- 回滚命令:`deploy/prod/update.sh <上一个不可变版本 tag>`(同一契约);
- 三应用服务整体回退,运行时 RELEASE.json 与 /health 回显上一版本;
- 本版本对 c83d214 系为元数据/附加表向后兼容(见 Migration 节),按迁移
  脚本 `--rollback` 语义可回退身份切换(有同 (content_hash,branch) 多行时
  拒绝并报错,不静默丢数据)。
