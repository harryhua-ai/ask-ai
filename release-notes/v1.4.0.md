# v1.4.0 — Widget Production Corrective（Authorized Websites · Unified Widget Workspace · Truthful Answer States）

## Version

v1.4.0

## User-visible changes

- New/default sites use the branded compact launcher: ✦ Ask AI.
- Existing legacy site launcher behavior remains compatible.
- Waiting for an answer uses: ✦ Preparing an answer…, replacing the former
  bouncing-dot presentation.
- The first real answer token replaces the waiting state in place.
- Mobile proactive engagement uses the lightweight nudge behavior rather than
  automatically opening the desktop-style mini conversation.
- Conversation hierarchy is simplified and no longer relies on repeated
  per-message role labels.

## Admin / operator changes

- Widget Experience and Widget Appearance are consolidated into one Widget
  workspace.
- The workspace contains: Entry & Engagement · Appearance · Authorized
  Websites · Preview & Test.
- Authorized Websites supports exact origin management.
- Wildcards, paths and queries are rejected.
- Admin-managed origins become authoritative after site creation rather than
  being overwritten by restart-time seed configuration.
- Launcher presentation becomes site-configurable.
- Preview uses the real Widget renderer.
- Preview/Test theme simulation is ephemeral and must not be persisted by
  Save.

## Compatibility / migration notes

- Includes the additive `launcher_presentation` schema migration.
- Migration is idempotent.
- Existing legacy/null launcher presentation semantics remain unchanged.
- Existing site origin and greeting semantics are preserved.
- No intentional breaking API change.
- No intentional authentication, retrieval, evidence-planning,
  ResponseStrategy or citation-semantics change.
